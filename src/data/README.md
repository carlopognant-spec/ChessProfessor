# Local opening repertoire

`openingPositions.json` is generated by `node scripts/build-opening-book.js`.
The browser loads this bundled data lazily; it does not contact the source sites.
No Explorer frequencies, PGN headers, ratings or engine scores determine book membership.

Base: JeffML/eco.json, revision `36cfd9227f553dec1d39ee20fa0775eea8f8e165`.
Source: https://github.com/JeffML/eco.json/tree/36cfd9227f553dec1d39ee20fa0775eea8f8e165
The upstream project's MIT license is preserved in `openingBook.LICENSE.txt`.
The dataset aggregates Lichess, Scid and other sources; see upstream README for provenance.
Generated metadata includes a SHA-256 checksum for each downloaded source file.

All 12,377 base sequences are replayed and validated with chess.js. Every intermediate
position is included, preserving turn, castling and legal en-passant rights, but ignoring
move counters. This recognizes transpositions without depending on a site's PGN format.
Game analysis closes the book permanently at the first unknown position.
Named mating traps do not override the existing final-mate classification.
The configured Explorer minimum of 20 is retained but no longer determines Libro.

`openingSupplements.json` holds two documented additions and their sources:
the Berlin `4.d4 Nxe4` continuation and the full published delayed Bowdler theory line.
These additions were selected after inspecting development games, so agreement on
games 1–6 and 10 is a regression check, not independent proof of general accuracy.
Annotations for games 7–9 were not used. The earlier ECOUrl predictions remain separate.

This repertoire is finite. An unknown continuation means absent from this repertoire,
not proof that it has never appeared in opening theory. Names and prose from the sources
are not bundled as the full opening database; the runtime index contains positions only.
